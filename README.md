# Serverless Image Resizer using AWS Lambda and S3

## 📌 Project Overview
This project automatically resizes images when uploaded to an S3 bucket using AWS Lambda.

---

## 🎯 Objective
To implement event-driven serverless architecture for image processing.

---

## 🧰 AWS Services Used
- AWS Lambda
- Amazon S3

---

## ⚙️ Workflow
1. Upload image to S3
2. S3 triggers Lambda
3. Lambda resizes image
4. Resized image stored in bucket
